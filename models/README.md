# models/

Fitted models are not included in this public repository.

`02_primary_ukbb_transport` expects `ukbb_transport_models_2023.RData` here: Cox models trained in UK Biobank and applied, with frozen coefficients, to the KPRB cohort. These models cannot be redistributed.

UK Biobank data are available to approved researchers through the UK Biobank access process. This study used UK Biobank data under Application #588633.

Do not commit files from this directory unless they have been explicitly reviewed and approved for public release.
